# Simulation model

The dynamic simulation layer introduces operational events that challenge architecture choices.

## Event classes

- traffic surge
- node failure
- link failure
- resource exhaustion
- security event
- user growth
- service demand spike

## Event structure

Each event should define:

- initial condition
- affected components
- change in demand or failure state
- allowed student response
- expected outcome
- scoring impact

## Educational purpose

Students learn that architecture quality is measured under stress, not only under normal operations.

# Scenario design rules

Each scenario should contain both human-readable and machine-readable design logic.

## Required scenario fields

- story
- users
- departments or business units
- locations
- functional requirements
- connectivity requirements
- security requirements
- availability requirements
- scalability requirements
- device categories
- acceptable device ranges
- relevant protocols
- relevant networking concepts
- possible SDN applications
- possible NFV applications
- possible VNFs
- simulation events
- validation rules

## Scenario principle

The user sees the operational summary, but the engine uses structured requirements and hidden rules to evaluate quality.

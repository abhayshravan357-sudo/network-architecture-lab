# Gameplay flow

The product follows a structured learning arc.

```text
Scenario
  -> Planning Quiz
  -> Resource Awareness
  -> Architecture Construction
  -> Architecture Validation
  -> SDN Transformation
  -> SDN Validation
  -> NFV/VNF Design
  -> VNF Orchestration
  -> Dynamic Network Simulation
  -> Final Evaluation
  -> Learning Report
```

## Stage details

### 1. Scenario
The student receives an operational story with constraints, users, departments, and services.

### 2. Planning quiz
A short quiz checks whether the student recognizes the core networking concepts relevant to the scenario.

### 3. Resource awareness
The player estimates device count, service placement, and topology shape before building.

### 4. Architecture construction
Students place devices, connect them, and assign roles and services.

### 5. Architecture validation
The engine checks whether the design meets connectivity, segmentation, redundancy, and service requirements.

### 6. SDN transformation
The architecture becomes programmable through SDN controllers, flows, and central control-plane logic.

### 7. NFV/VNF design
The student decides which functions should be virtualized and how service chains should behave.

### 8. Orchestration
The platform instantiates, scales, monitors, and migrates VNFs according to demand and constraints.

### 9. Dynamic simulation
The system introduces traffic spikes, outages, link failures, and resource shortages.

### 10. Final evaluation
The system summarizes score, reasoning quality, and conceptual understanding.

### 11. Learning report
The student receives explanations of what was correct, what missed, and why it mattered.

# UI design rules

The interface should balance educational clarity with simulation energy.

## Core principles

- clear scenario briefs
- guided progression across stages
- visible status and guidance
- conceptual explanations behind answers
- feedback loops with hints and scoring
- readable network canvas with logical clarity

## Interface sections

- home screen
- scenario overview
- quiz interface
- builder canvas
- validation panel
- SDN workspace
- NFV workspace
- orchestration panel
- simulation timeline
- final report

## Design intention

The interface should teach first and impress second. Aesthetic polish matters, but it must not hide the architecture logic.
